# AI Travel Planner Web
Responsive Flask website for phone and laptop.

Run: `pip install -r requirements.txt` then `python app.py`, open http://127.0.0.1:5000.

For live AI/weather set `GEMINI_API_KEY`, `OPENWEATHER_API_KEY`, and `SECRET_KEY`.

Deploy on Render: Build `pip install -r requirements.txt`; Start `gunicorn app:app`.
